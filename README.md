# xuyang.me

Personal website and developer playground of **Xuyang Kang**, hosted on GitHub Pages.

🌐 Live Site: [https://xuyang.me](https://xuyang.me)

---

## 🛠 Tech Stack & Features

- **Zero-build static website**: Pure HTML5, CSS3, and JavaScript.
- **Handcrafted typography**: Features the Virgil font (`Virgil.woff2`) for an approachable, hand-drawn look.
- **Embedded Experiments & Tools**:
  - `/resume`: Fast redirect to [resume.pdf](resume.pdf).
  - `/market`: "炼金控制台" (Multi-asset financial monitor with TradingView widgets).
  - `/py`: Client-side Python REPL powered by Brython.

---

## 🚀 Local Development

No package installation or build step needed. Simply serve the directory with any static server:

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

Then visit `http://localhost:8000`.
